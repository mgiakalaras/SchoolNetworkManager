# School Network Manager

<img width="1869" height="2055" alt="image" src="https://github.com/user-attachments/assets/ae8f4ad4-035b-4cc3-bd05-859c4dba4e4b" />


Το **School Network Manager** είναι εφαρμογή καταγραφής, οργάνωσης και διαχείρισης του σχολικού δικτύου
και του εξοπλισμού των εργαστηρίων πληροφορικής. Τρέχει σε έναν server του σχολείου (π.χ. ZimaOS / Docker)
και η ομάδα πληροφορικής δουλεύει από οποιονδήποτε browser του σχολικού δικτύου — ο καθένας με δικό του λογαριασμό.

**Τρέχουσα έκδοση: 2.15.3** · [Τι νέο υπάρχει](CHANGELOG.md)

## Δυνατότητες

**Συσκευές & δίκτυο**
- Καταγραφή συσκευών με τύπο, χαρακτηριστικά (CPU, RAM, δίσκοι, toner…), κωδικούς (κρυπτογραφημένους) και σημειώσεις
- 📌 Static / 🔄 Dynamic διευθύνσεις και «ξεσκαρτάρισμα» των άδειων διευθύνσεων DHCP
- Σάρωση δικτύου, αυτόματη συμπλήρωση MAC / ονόματος / κατασκευαστή / ports, Wake-on-LAN
- Αυτόματος έλεγχος Online / Offline, ιστορικό χρήσης ανά συσκευή, γραφήματα εβδομάδας
- Φύλακας Veyon: ειδοποίηση όταν κάποιος σταματήσει την υπηρεσία Veyon
- **Agent για Windows**: κάθε υπολογιστής στέλνει μόνος του όνομα, IP, MAC, χαρακτηριστικά, δίσκους, Veyon
  και εγκατεστημένα προγράμματα — με αναζήτηση λογισμικού και ειδοποίηση για νέα προγράμματα
- Import / Export Excel, εξαγωγή για Veyon, σύνδεση με Pi-hole και MySpeed

**Χώροι & εργαστήρια**
- Χώροι με γρήγορη εικόνα, δημιουργία χώρου και προσθήκη συσκευών
- Κάτοψη χώρου και πλάνο θέσεων μαθητών ανά τμήμα
- Εκτυπώσεις λιστών ανά χώρο

**Καθημερινή λειτουργία**
- Βιβλίο βλαβών και **δημόσια σελίδα** όπου μαθητές / εκπαιδευτικοί δηλώνουν βλάβη χωρίς κωδικό
- Αναλώσιμα με ειδοποίηση όταν τελειώνουν
- Αρχεία & εργαλεία: κοινή βιβλιοθήκη με utilities, εγκαταστάτες, scripts και drivers
- Γεννήτρια κωδικών με ιστορικό (ποιος άλλαξε ποιον κωδικό, πού και πότε)
- Κανονισμός εργαστηρίων & κανόνες μαθητών: επεξεργασία, Word, εκτύπωση ως επίσημο έγγραφο ή αφίσα
- Ετήσια αναφορά για τη Διεύθυνση ή τον τομεάρχη (όλο το σχολείο ή ένα εργαστήριο)

**Ομάδα & ασφάλεια**
- Λογαριασμοί χρηστών με δικό τους κωδικό· κοινά δεδομένα και καταγραφή «ποιος το έκανε»
- Αυτόματα αντίγραφα ασφαλείας κάθε μέρα και επαναφορά με ένα κλικ
- Θέματα εμφάνισης (φωτεινά / σκοτεινά), οδηγός βοήθειας μέσα στην εφαρμογή

## Εγκατάσταση (server με Docker)

Η εφαρμογή διανέμεται ως Docker image και χρειάζεται `network_mode: host`
(για MAC, σάρωση δικτύου και Wake-on-LAN).

```yaml
services:
  schoolnetworkmanager:
    image: ghcr.io/mgiakalaras/schoolnetworkmanager:latest
    container_name: schoolnetworkmanager
    restart: unless-stopped
    network_mode: host
    environment:
      TZ: Europe/Athens
      ADMIN_PASSWORD: "ΑΛΛΑΞΕ-ΜΕ"
    volumes:
      - /DATA/AppData/schoolnetworkmanager/data:/app/data
      - /DATA/AppData/schoolnetworkmanager/uploads:/app/wwwroot/uploads
```

Η εφαρμογή ανοίγει στο `http://<ip-του-server>:5055`.

- **Portainer / ZimaOS:** αναλυτικά βήματα στο [ΟΔΗΓΙΕΣ-PORTAINER.md](ΟΔΗΓΙΕΣ-PORTAINER.md).
- Πρώτη σύνδεση: όνομα `admin` (ή κενό) και ο κωδικός `ADMIN_PASSWORD`.
  Μετά: ⚙️ → **Χρήστες** → λογαριασμός για κάθε μέλος της ομάδας.
- Δημόσια σελίδα για μαθητές: `http://<ip-του-server>:5055/Public`

### Ενημέρωση σε νέα έκδοση
Portainer → Stacks → `schoolnetworkmanager` → **Update the stack** με **Re-pull image**.
Τα δεδομένα (βάση, κλειδιά, αρχεία, αντίγραφα) μένουν στα volumes και δεν αλλάζουν.

## Ασφάλεια δεδομένων

Η βάση περιέχει IP, MAC και κωδικούς συσκευών (κρυπτογραφημένους με κλειδιά στο `data/keys`).
- Μην ανεβάζετε ποτέ τη βάση, τα αντίγραφα ασφαλείας ή τον πραγματικό `ADMIN_PASSWORD` σε δημόσιο χώρο.
- Τα αυτόματα αντίγραφα βρίσκονται στο `data/backups` — κατεβάζετε περιοδικά ένα και εκτός server.
- Η εφαρμογή προορίζεται για το εσωτερικό δίκτυο του σχολείου, όχι για έκθεση στο διαδίκτυο.

## Παλιά έκδοση για Windows (v1.x)

Η πρώτη έκδοση διανεμόταν ως Windows installer (`SchoolNetworkManagerSetup.exe`) και έτρεχε τοπικά σε έναν υπολογιστή.
Παραμένει στα **Releases** για όποιον τη χρειάζεται, αλλά **δεν αναπτύσσεται πλέον** — όλες οι νέες δυνατότητες
είναι στην έκδοση server. Τα δεδομένα της μεταφέρονται με Export → Import Excel.
