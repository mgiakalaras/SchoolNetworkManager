\# School Network Manager

<img width="1870" height="1480" alt="image" src="https://github.com/user-attachments/assets/677c8799-eb1a-4cfd-8dca-4864caf566f9" />


Το \*\*School Network Manager\*\* είναι μια εφαρμογή καταγραφής, οργάνωσης και διαχείρισης σχολικού δικτύου και τεχνολογικού εξοπλισμού.



Η εφαρμογή έχει σχεδιαστεί για χρήση σε σχολικές μονάδες, ώστε ο υπεύθυνος εργαστηρίου ή ο εκπαιδευτικός πληροφορικής να μπορεί να παρακολουθεί εύκολα υπολογιστές, φορητές συσκευές, διαδραστικούς πίνακες, δικτυακό εξοπλισμό και λοιπές συσκευές.



\---



\## Κύριες δυνατότητες



\- Καταγραφή συσκευών σχολικού δικτύου

\- Κατηγοριοποίηση ανά τύπο συσκευής

\- Import δεδομένων από Excel

\- Export δεδομένων σε Excel

\- Αναζήτηση, φίλτρα και ταξινόμηση

\- Έλεγχος Online / Offline

\- Dashboard με στατιστικά

\- Ρυθμίσεις τίτλου, υπότιτλου και λογότυπου σχολείου

\- Σελίδα πληροφοριών εφαρμογής

\- Τοπική βάση δεδομένων SQLite

\- Windows installer



\---



\## Εγκατάσταση για απλούς χρήστες



Για να εγκαταστήσετε την εφαρμογή:



1\. Μεταβείτε στην ενότητα \*\*Releases\*\* του GitHub repository.

2\. Κατεβάστε το αρχείο:



&#x20;  `SchoolNetworkManagerSetup.exe`



3\. Εκτελέστε το αρχείο εγκατάστασης.

4\. Ακολουθήστε τα βήματα του installer.

5\. Μετά την εγκατάσταση, ανοίξτε την εφαρμογή από το εικονίδιο:



&#x20;  `School Network Manager`



Η εφαρμογή ανοίγει τοπικά στον browser στη διεύθυνση:



`http://localhost:5055`



\---



\## Πρώτη χρήση



Μετά την πρώτη εκκίνηση, η εφαρμογή ξεκινά με άδεια βάση δεδομένων.



Ο χρήστης μπορεί:



1\. Να καταχωρήσει συσκευές χειροκίνητα.

2\. Να κάνει import από αρχείο Excel.

3\. Να αλλάξει τίτλο, υπότιτλο και λογότυπο από τις Ρυθμίσεις.



\---



\## Import από Excel



Η εφαρμογή υποστηρίζει εισαγωγή δεδομένων από αρχείο `.xlsx`.



Το Excel μπορεί να περιέχει στήλες όπως:



\- IP Address

\- Name

\- MAC Address

\- Location

\- Username

\- Password

\- Extras

\- LAN Messenger

\- Veyon

\- NOTES

\- Σημειώσεις



Κατά το import:



\- Αν μια IP δεν υπάρχει, δημιουργείται νέα εγγραφή.

\- Αν μια IP υπάρχει ήδη, ενημερώνεται η υπάρχουσα εγγραφή.

\- Οι γραμμές χωρίς IP αγνοούνται.

\- Ο τύπος συσκευής δεν επηρεάζεται από το Excel και επιλέγεται μέσα από την εφαρμογή.



\---



\## Τύποι συσκευών



Κάθε εγγραφή μπορεί να πάρει τύπο συσκευής, όπως:



\- Υπολογιστής

\- Laptop

\- Tablet

\- Κινητό

\- Server

\- Raspberry Pi / SBC

\- Διαδραστικός Πίνακας

\- Projector

\- Εκτυπωτής

\- Πολυμηχάνημα

\- Switch

\- Router

\- Access Point

\- NAS / Storage

\- IP Camera / Webcam

\- VoIP Τηλέφωνο

\- UPS

\- IoT / Arduino

\- Άλλο

\- Άγνωστο



Οι εγγραφές με όνομα `EMPTY` θεωρούνται κενές θέσεις και δεν εμφανίζουν τύπο συσκευής.



\---



\## Dashboard



Το Dashboard εμφανίζει συνοπτικά:



\- Σύνολο συσκευών

\- Συσκευές με Veyon

\- Συσκευές με LAN Messenger

\- Συσκευές ανά τύπο

\- Online / Offline / Άγνωστη κατάσταση

\- Συσκευές ανά χώρο

\- Τελευταίες καταχωρήσεις



Από το Dashboard μπορεί επίσης να γίνει έλεγχος Online / Offline.



\---



\## Φίλτρα και ταξινόμηση



Στη λίστα συσκευών υπάρχουν φίλτρα για:



\- Αναζήτηση με IP, όνομα, MAC, χώρο, τύπο ή σημειώσεις

\- Veyon

\- LAN Messenger

\- Status

\- Ταξινόμηση ανά IP, τύπο, όνομα, χώρο, Veyon, LAN Messenger ή status



\---



\## Ρυθμίσεις



Από τη σελίδα \*\*Ρυθμίσεις\*\* μπορεί να αλλάξει:



\- Ο τίτλος της εφαρμογής

\- Ο υπότιτλος

\- Το λογότυπο του σχολείου



Το λογότυπο αποθηκεύεται τοπικά στον υπολογιστή του χρήστη.



\---



\## Έξοδος από την εφαρμογή



Η εφαρμογή εκτελείται τοπικά στο παρασκήνιο.



Για σωστό κλείσιμο:



1\. Πατήστε \*\*Έξοδος\*\* από το μενού.

2\. Επιλέξτε \*\*Κλείσιμο εφαρμογής\*\*.



Το απλό κλείσιμο της καρτέλας του browser δεν τερματίζει την εφαρμογή.



\---



\## Απεγκατάσταση



Η εφαρμογή μπορεί να απεγκατασταθεί από:



`Windows Settings → Apps → Installed apps → School Network Manager → Uninstall`



ή από τη συντόμευση απεγκατάστασης στο Start Menu.



\---



\## Δεδομένα εφαρμογής



Η εφαρμογή χρησιμοποιεί τοπική βάση δεδομένων SQLite.



Τα δεδομένα του χρήστη αποθηκεύονται τοπικά στον υπολογιστή του και δεν αποστέλλονται σε εξωτερικό server.



\---



\## Σημείωση ασφαλείας



Η εφαρμογή μπορεί να περιέχει πεδία όπως usernames, passwords ή τεχνικές σημειώσεις.



Ο χρήστης πρέπει να προσέχει:



\- Να μην κοινοποιεί τη βάση δεδομένων.

\- Να μην ανεβάζει αρχεία export σε δημόσιους χώρους.

\- Να κρατά αντίγραφα ασφαλείας των δεδομένων του.



\---
